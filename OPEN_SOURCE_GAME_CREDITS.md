# StudyShelf Open-Source Game Additions

This patch adds catalog entries for 32 browser games from **mashukui/web-games**:

- Repository: https://github.com/mashukui/web-games
- Live games: https://mashukui.github.io/web-games/
- License declared by upstream repository: MIT
- Author: mashukui

The upstream repository describes its games as self-contained HTML5 games and declares the project under the MIT License. This patch links to the author's published game pages rather than copying their game code. The thumbnails in `public/studyshelf-open-source/` are original StudyShelf-created SVG artwork, not upstream game screenshots.

Upstream license text: https://github.com/mashukui/web-games/blob/main/LICENSE

MIT notice from upstream should be retained if you later copy or redistribute the source files themselves. The live iframe pages are third-party content and remain hosted by the upstream author; their availability and embedding behavior can change. Check each page inside StudyShelf before promoting it.

This patch is not a legal audit of any pre-existing StudyShelf entries. It only documents these 32 additions.

StudyShelf Big Titles catalog patch

Preserves the existing 55 entries and adds 21 titles: Dune!, Crazy Cattle 3D, Snow Rider 3D, Riddle School 1–5, Riddle Transfer 1–2, Duck Life 1–4, Duck Life: Treasure Hunt, Duck Life: Space, Duck Life: Adventure, Duck Life: Battle, Drift Boss, Run 3, and Slope.

Install: back up C:\Users\logan\StudyShelf3\src\games.js, then extract this ZIP into C:\Users\logan\StudyShelf3 and overwrite src/games.js. Run `npm.cmd run build`.

The project build validates the catalog syntax, not remote iframe permissions. Check the new games in the local site before pushing live. Crazy Cattle 3D uses its itch.io HTML5 build; Riddle School and Duck Life use third-party browser-hosted pages. This patch does not redistribute game files.
